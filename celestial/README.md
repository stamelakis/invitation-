# Celestial Pearl — ψηφιακή πρόσκληση γάμου

Ανδρέας & Λίνα · Σάββατο 26 Σεπτεμβρίου 2026

Μία αυτόνομη σελίδα (`celestial/index.html`) — χωρίς build, χωρίς εξαρτήσεις.
Όλα τα υλικά (περλέ χαρτί, διάτρητη κοπή, vellum, θερμοτυπία σαμπανί,
μαργαριτάρι, σατέν φόντο, φως νερού) σχεδιάζονται με SVG/CSS μέσα στο αρχείο.

## Οι τρεις σκηνές

| | Σκηνή | Τι δείχνει |
|---|---|---|
| 1 | **Κλειστή πρόσκληση** | Η στοίβα των τοξωτών καρτών με την κορδέλα vellum και τη σφραγίδα-μαργαριτάρι. Άγγιγμα στη σφραγίδα → σκηνή 2. |
| 2 | **Άνοιγμα** | Όλα τα μέρη χωρίζουν με **μία κοινή, απαλή κίνηση** (ίδια διάρκεια & καμπύλη για κάθε κομμάτι): η βεντάλια-κοχύλι αριστερά, τα δύο φύλλα δεξιά, η κορδέλα από κάτω. Ακολουθεί το σώμα της πρόσκλησης. |
| 3 | **Ο φάκελος κλείνει** | Μετά το κουμπί «Αποστολή»: το κοχύλι κλείνει και ο φιόγκος δένεται πάνω του. |

Η κοινή κίνηση ελέγχεται από τη μεταβλητή `--drift` (προεπιλογή `2200ms`)
στο `:root`. Άλλαξέ τη μία φορά και αλλάζει ο ρυθμός όλης της σκηνής 2.

## Πού αλλάζεις τα στοιχεία

Τα δυναμικά στοιχεία είναι συγκεντρωμένα στο αντικείμενο `CFG`, στην αρχή
του `<script>`. Τα σταθερά κείμενα (αναγγελία, ημερομηνία, ώρες, οικογένειες,
κουμπάροι, quote) είναι στο HTML, με σχόλια που δείχνουν τον αριθμό του
κάθε στοιχείου.

| # | Στοιχείο | Πού |
|---|---|---|
| 1 | Ονόματα + κουμπί φωτογραφιών | `CFG.couple`, `CFG.photos` · markup: `#leafA` |
| 2 | Αναγγελία / φράση πρόσκλησης | `#leafA` → `.eyebrow` |
| 3 | Ημερομηνία γάμου | `#leafB` |
| 4 | Ώρα τελετής | `#leafB` και η κάρτα «Η τελετή» |
| 5 | Τόπος τελετής + Google Maps | κάρτα «Η τελετή» · `CFG.ceremony.query` |
| 6 | Χώρος δεξίωσης + Google Maps | κάρτα «Η δεξίωση» · `CFG.reception.query` |
| 7 | Ώρα δεξίωσης | `#receptionTime` |
| 8 | Οικογένειες | κάρτα «Οι οικογένειες» |
| 9 | Κουμπάροι | κάρτα «Οι κουμπάροι» |
| 10 | RSVP | φόρμα `#rsvpForm` |
| 11 | Τηλέφωνα + αντιγραφή | `CFG.phones` |
| 12 | Διαμονή | `CFG.stay`, `CFG.stayQuery` |
| 13 | Δώρο + αντιγραφή IBAN | `CFG.iban`, `CFG.ibanPretty` |
| 14 | Μονόγραμμα & quote | κάρτα με το `Α & Λ` |
| 15 | Πλαίσιο ευχής | `#fWish` |
| 16 | Κουμπί «Αποστολή» | `#sendBtn` · `CFG.rsvp` |

### Φωτογραφίες (στοιχείο 1)

```js
photos: {
  andreas: ["photos/andreas-1.jpg", "photos/andreas-2.jpg"],
  lina:    ["photos/lina-1.jpg"]
}
```

Βάλε τα αρχεία σε έναν φάκελο `celestial/photos/`. Όσο οι λίστες είναι
κενές, το κουμπί ανοίγει κανονικά και γράφει «Οι φωτογραφίες προστίθενται
σύντομα».

### Διαμονή (στοιχείο 12)

```js
stay: [
  { name:"Όνομα ξενοδοχείου", note:"12 λεπτά από το κτήμα", url:"https://…" }
]
```

Χωρίς καταχωρήσεις εμφανίζεται μόνο το κουμπί αναζήτησης καταλυμάτων
κοντά στο κτήμα.

### Αποστολή της απάντησης (στοιχείο 16)

Προεπιλογή: `CFG.rsvp.endpoint = ""`. Με κενό endpoint το κουμπί ανοίγει
την εφαρμογή email του καλεσμένου, με όλα τα πεδία και την ευχή έτοιμα,
προς `CFG.rsvp.email`. Δουλεύει αμέσως και δεν εκθέτει τη διεύθυνση σε
τρίτη υπηρεσία.

Για **σιωπηλή αποστολή στο παρασκήνιο** (ο καλεσμένος δεν βγαίνει από τη
σελίδα), βάλε ένα endpoint φόρμας:

```js
rsvp: { endpoint:"https://formspree.io/f/xxxxxxxx", … }   // Formspree
rsvp: { endpoint:"https://formsubmit.co/ajax/<τυχαίο-token>", … }  // FormSubmit
rsvp: { endpoint:"https://api.web3forms.com/submit", … }   // Web3Forms
```

Προτίμησε το token/hash της υπηρεσίας αντί για τη διεύθυνση email, ώστε να
μη φαίνεται το mail στον κώδικα της σελίδας. Αν το αίτημα αποτύχει, η
σελίδα πέφτει αυτόματα πίσω στο mailto — καμία απάντηση δεν χάνεται.

## Δοκιμή τοπικά

```sh
python3 -m http.server 8000
# → http://localhost:8000/celestial/
```

## Προσβασιμότητα & απόδοση

* Πλήρης πλοήγηση με πληκτρολόγιο· ορατό focus σε κάθε κουμπί.
* `prefers-reduced-motion`: οι κινήσεις απενεργοποιούνται.
* Καμία εξωτερική εξάρτηση πέρα από τις γραμματοσειρές Google
  (Cormorant Garamond, EB Garamond — και οι δύο με ελληνικά).
* Χωρίς εικόνες: όλα τα γραφικά είναι SVG, ~86 KB συνολικά (μία σελίδα).
