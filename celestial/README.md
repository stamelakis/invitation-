# Celestial Pearl — ψηφιακή πρόσκληση γάμου

Ανδρέας & Λίνα · Σάββατο 26 Σεπτεμβρίου 2026

Κάδρο **9:16** σε κάθε οθόνη. Τα υλικά είναι **οι πραγματικές φωτογραφίες**
(`celestial/art/`), όχι σχεδιασμένα γραφικά: ο φάκελος είναι η φωτογραφία σε
πλήρη ανάλυση, και το χαρτί της κάρτας είναι κομμένο από το ανάγλυφο damask
της ίδιας λήψης.

## Οι τρεις σκηνές

| | Σκηνή | |
|---|---|---|
| 1 | **Κλειστός φάκελος** | Άγγιγμα στο μαργαριτάρι — το κουμπί κάθεται ακριβώς πάνω του. |
| 2 | **Η κάρτα** | Βγαίνει από τον φάκελο· ο φάκελος κατεβαίνει και μένει από πίσω. Κάθε στοιχείο έχει το δικό του κουμπί. |
| 3 | **Αποστολή** | Η κάρτα διπλώνει στα τρία, μπαίνει στον φάκελο, και ο φάκελος κλείνει όπως ήταν στην αρχή. |

Η περιοχή αφής κάθε κουμπιού είναι 16 px μεγαλύτερη από το ίδιο το κουμπί,
ώστε να πατιέται άνετα με το δάχτυλο.

## Η ευχή

Το πλαίσιο της ευχής είναι ένα `textarea` με διάφανο κείμενο πάνω από έναν
καθρέφτη που ζωγραφίζει τα ίδια γράμματα. Τα **δέκα πιο πρόσφατα γράμματα**
κρατούν λάμψη που σβήνει προς τα πίσω, και σε κάθε πληκτρολόγηση πετάγονται
δύο σπίθες από τον κέρσορα. Η αποστολή θέλει πρώτα επιλογή RSVP.

## Πού αλλάζουν τα στοιχεία

Όλα τα δυναμικά είναι στο αντικείμενο `CFG`, στην αρχή του `<script>`:

```js
portraits: { andreas:{ name:"Ανδρέας", photos:["photos/a1.jpg", …] }, … }
maps:      { ceremony:"…", reception:"…", stay:"…" }
phones:    [{ who, label, tel, pretty }, …]
iban:      "GR87…"
event:     { title, startUTC, endUTC, location, notes }
rsvp:      { endpoint:"", email:"…", subject:"…" }
```

Τα σταθερά κείμενα (αναγγελία, ώρες, οικογένειες, κουμπάροι, quote) είναι
στο HTML, με σχόλια που δείχνουν κάθε σημείο.

**Πορτρέτα:** βάλτε τα αρχεία σε `celestial/photos/` και τα URL στο
`CFG.portraits`. Όσο οι λίστες είναι κενές, το κουμπί ανοίγει κανονικά και
γράφει «Τα πορτρέτα προστίθενται σύντομα».

**Αποστολή:** με κενό `endpoint` ανοίγει η εφαρμογή email του καλεσμένου,
με την απάντηση και την ευχή έτοιμες. Για σιωπηλή αποστολή στο παρασκήνιο
βάλτε ένα endpoint φόρμας (Formspree / FormSubmit / Web3Forms) — προτιμήστε
το token της υπηρεσίας αντί για τη διεύθυνση, ώστε να μη φαίνεται το mail
στον κώδικα. Αν το αίτημα αποτύχει, πέφτει αυτόματα πίσω στο mailto.

## Γεωμετρία & υλικά

```
φωτογραφία φακέλου   1492 × 1054
κέντρο μαργαριταριού x = 769 → 51.54 %   y = 624 → 59.20 %   (προσαρμογή κύκλου)
χαρτί κάρτας         κομμένο από x 285 y 268, 340 × 162 της ανοιχτής λήψης
```

Το κουμπί του μαργαριταριού κρατά το ίδιο κομμάτι της φωτογραφίας, κομμένο
σε κύκλο με απαλή άκρη, ώστε στο άγγιγμα να ανασηκώνεται το *πραγματικό*
μαργαριτάρι χωρίς ορατή ραφή. Το χαρτί της κάρτας πέρασε από υψιπερατό
φίλτρο (αφαίρεση του φωτισμού της λήψης) και καθρεφτίστηκε σε πλακίδιο
2×2, ώστε να επαναλαμβάνεται χωρίς ραφή· ο φωτισμός μπαίνει ξανά από το CSS.

