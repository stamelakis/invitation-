# Celestial Pearl — ψηφιακή πρόσκληση γάμου

Ανδρέας & Λίνα · Σάββατο 26 Σεπτεμβρίου 2026

Τα υλικά είναι **οι πραγματικές φωτογραφίες** (`celestial/art/`), όχι
σχεδιασμένα γραφικά. Η σελίδα δεν ξαναζωγραφίζει την υφή — τη χρησιμοποιεί.

## Πού βρισκόμαστε

| Βήμα | Κατάσταση | |
|---|---|---|
| **1** | **Ο φάκελος κλειστός + το κουμπί στο μαργαριτάρι** | ✅ έτοιμο |
| 2 | Το περιεχόμενο της ανοιχτής πρόσκλησης | εκκρεμεί |
| 3 | Ο φάκελος κλείνει μετά την «Αποστολή» | εκκρεμεί |

## Βήμα 1 — πώς δουλεύει

`index.html` δείχνει τη φωτογραφία `art/envelope-closed.webp` σε πλήρη
ανάλυση. Πάνω της, ακριβώς στο μαργαριτάρι, κάθεται ένα κουμπί.

**Γεωμετρία.** Το κέντρο του χρυσού καπακιού μετρήθηκε πάνω στη φωτογραφία
με προσαρμογή κύκλου στο περίγραμμά του:

```
φωτογραφία   1492 × 1054 px
κέντρο       x = 769 px → 51.54 %      y = 624 px → 59.20 %
ακτίνα καπακιού ≈ 46 px  ·  περιοχή αφής ≈ 63 px
```

Αυτοί οι τρεις αριθμοί ζουν ως `--px`, `--py`, `--pw` στο `:root`. Όλα τα
υπόλοιπα (θέση, μέγεθος, ευθυγράμμιση του φόντου του κουμπιού) υπολογίζονται
από αυτούς με `calc`, οπότε το κουμπί μένει κλειδωμένο στο μαργαριτάρι σε
κάθε μέγεθος οθόνης. Μετρημένη απόκλιση: **0,01 px** σε desktop και κινητό.

**Το κουμπί δεν είναι σχέδιο.** Κρατά το ίδιο κομμάτι της φωτογραφίας,
κομμένο σε κύκλο με απαλή άκρη (`mask-image`), ώστε στο άγγιγμα να
ανασηκώνεται και να πιάνει φως το *πραγματικό* μαργαριτάρι — χωρίς ορατή
ραφή με τη γύρω εικόνα.

**Το σατέν γύρω-γύρω.** Οι άκρες της φωτογραφίας σβήνουν μέσα σε ένα πεδίο
στον ίδιο ακριβώς τόνο με τις άκρες της (δειγματοληψία: πάνω `#c3b1a2`,
κάτω `#b9a595`), οπότε το ύφασμα απλώς συνεχίζει σε κάθε αναλογία οθόνης.

## Τι χρειάζεται για το βήμα 2

Η `art/envelope-open.webp` έχει **τυπωμένα τα δείγματα ονομάτων** του style
sheet — Στέφανος & Ιόλη, 28.06.2027, Άγιος Νικόλαος Παλαιού Φαλήρου. Δεν
μπορεί να μείνει έτσι. Δύο δρόμοι:

1. **Νέο render** της ανοιχτής σκηνής με τα αληθινά στοιχεία (Ανδρέας &
   Λίνα, 26.09.2026, Παρεκκλήσι Αγίου Γεωργίου, Κτήμα Jockey).
2. **Λευκές κάρτες** στο render, και το πραγματικό κείμενο μπαίνει από πάνω
   ως ζωντανό HTML — έτσι διορθώνεται όποτε θέλουμε, χωρίς νέα φωτογραφία.

Προς το παρόν η φωτογραφία μπαίνει προσωρινά, μόνο για να δουλεύει το
άνοιγμα.

## Αρχεία

```
celestial/
  index.html                 βήμα 1
  art/envelope-closed.webp   ο φάκελος κλειστός   (1492×1054)
  art/envelope-open.webp     η ανοιχτή σκηνή      (προσωρινή, λάθος ονόματα)
  draft-svg.html             προηγούμενη δοκιμή, σχεδιασμένη σε SVG/CSS
```

Το `draft-svg.html` κρατά και τα 16 στοιχεία της πρόσκλησης (RSVP, IBAN,
τηλέφωνα, ευχή) ως ζωντανό HTML — από εκεί θα έρθει το περιεχόμενο στο
βήμα 2.

## Δοκιμή τοπικά

```sh
python3 -m http.server 8000
# → http://localhost:8000/celestial/
```
